# Reservation Seats for Church Events

نظام بسيط لحجز مقاعد حفلات وفعاليات الكنيسة أونلاين، مبني باستخدام **HTML + CSS + JavaScript** ويعمل بالكامل على **GitHub Pages** بدون باك‑إند.

## المميزات

- عرض خريطة كاملة للمقاعد (VIP / Regular / Back) مع حالة كل كرسي (متاح / محجوز / مختار).
- حجز مقعد باسم الزائر مع بياناته (الاسم، الموبايل، الإيميل، الملاحظات).
- اختيار عدد المرافقين وحساب السعر الإجمالي تلقائياً.
- اختيار طريقة الدفع (Phone Cash / InstaPay) مع توليد QR Code ومعلومة الدفع.
- توليد كود تتبع للحجز يمكن نسخه أو إرساله على واتساب.
- لوحة تحكم Admin (محلية) لعرض كل الحجوزات وتغيير حالتها (مؤكد / مرفوض).
- إمكانية تغيير أسعار التذاكر وعدد الصفوف وعدد المقاعد لكل منطقة ويتم حفظها في المتصفح (localStorage).

## طريقة التشغيل محلياً

1. نزّل المشروع (Download ZIP أو git clone).
2. افتح ملف `index.html` في المتصفح.
3. لتجربة لوحة التحكم:
   - البريد: `admin@church.com`
   - كلمة المرور: `Church2026`  
   (للاستخدام التجريبي فقط، ليست أمان حقيقي لأنها ظاهرة في الكود.)

## النشر على GitHub Pages

1. ارفع ملفات المشروع (`index.html`, `styles.css`, `app.js`) إلى الفرع `main`.
2. من إعدادات الريبو → **Pages** → اختَر `Deploy from branch` ثم الفرع `main` والمجلد `/root`.
3. بعد ثواني هتحصل على لينك للموقع ويمكن مشاركته مع الكنيسة والزوار.
